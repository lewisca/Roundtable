# Roundtable

The family tree you build together, and keep adding to.

Roundtable is a collaborative family-reunion tree app. Share one board code and
everyone fills in the branch they know best — new babies, new marriages,
corrections — years later. Built as a single, self-contained, dependency-free
`index.html` (just open it in a browser).

## Features

- **Shared boards** — join a board with a 6-character code; data persists locally per board.
- **Build the tree** — add people, spouses/partners, dates, places, and notes; add children and siblings.
- **Generations at a glance** — up to 8 colour-coded generations with connectors, collapse/expand, zoom, and search.
- **Duplicates, handled gently** — two entries for the same person are flagged side by side with a chat, never silently merged.
- **Change log & undo** — every add, edit, and removal is recorded with who did it and when.
- **Projection View** — a read-only, full-screen live display for a TV or projector at the reunion.
- **Download** — export the whole tree (with the change log) as a printable PDF or a PNG image.

## Running it

Open `index.html` in any modern browser. No build step, no server, no accounts.

To explore a sample family, join board code **`V3L4Y2`**.
